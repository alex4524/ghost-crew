Every web app is haunted.

Ghost Crew is a small skeleton for browser QA. You describe a walk through your page in a few lines of YAML. A ghost takes that walk in a real Chrome, notices what breaks, and brings back a spirit photograph with every problem circled.

How a haunting works

Four steps, and the first one is the only one you write.

  1. Write a ghost

    One file per concern. Targets are what a person sees: a button’s text, a field’s label.

    ghost: The Locked Door
haunts: /index.html
senses:
  - keyboard-reach:
      targets: [Book now, Reserve]

  2. Summon the crew

    One Chrome, one private context per ghost, four walking at once.

    $ poltergeist https://your.app \
    --ghosts ghosts/
✦ The Locked Door   1 haunting
✦ The Lantern Dimmer  4 hauntings

  3. Read the spirit photograph

    Every haunting is circled on the page itself, numbered to match the list beside it. Flip to the living page to compare.

  4. Exorcise, then compare

    Pass last night’s report as a baseline. The record splits hauntings into new, still haunting and exorcised.

    $ poltergeist https://your.app \
    --baseline last/report.json
9 exorcised, 0 new

One skeleton, two apps

The core walks pages, takes photographs and writes the record. An app only adds senses, a theme and its own crew. Both apps below are about 220 lines each.

Poltergeist

Finds the parts of a page that some people cannot see, reach or read.

  • axe runs axe-core and circles every failing element
  • keyboard-reach tabs through the page and finds what the keyboard never reaches
  • focus-visible catches focus rings that were styled away

With no ghosts at all, npx poltergeist <url> runs a desktop sweep, a keyboard walk and a phone visit.

Phantom Form

Types what real people type into your forms, one cursed value at a time.

  • Fourteen curses: emoji names, apostrophes, right-to-left text, markup, negative nights
  • Each curse gets a fresh page and its own photograph
  • Catches crashes, script injection, broken characters, blank answers accepted and real answers refused

With no ghosts at all, npx phantom-form <url> finds the first form and picks curses by field type.

A new kind of ghost is one file

import { defineSense } from 'ghost-crew';

defineSense('no-lorem-ipsum', {
  async run(ctx) {
    const hit = await ctx.page.getByText(/lorem ipsum/i).first();
    if (await hit.count())
      await ctx.haunt({
        mood: 'mischievous',
        title: 'Placeholder text shipped',
        locator: hit,   // circled in the photograph
      });
  },
});

Summon one yourself

You need Node 20 or newer and Google Chrome. Only haunt sites you own or may test.

# one command, nothing to install
$ npx -y -p github:alex4524/ghost-crew poltergeist https://your.app
$ npx -y -p github:alex4524/ghost-crew phantom-form https://your.app/signup

# or clone it and watch both apps haunt the demo inn
$ git clone https://github.com/alex4524/ghost-crew && cd ghost-crew
$ npm install && npm run midnight
$ open site/reports/poltergeist/index.html

# give your Kiro agent the crew: .kiro/settings/mcp.json
{ "mcpServers": { "ghost-crew": { "command": "npx",
    "args": ["-y", "-p", "github:alex4524/ghost-crew", "ghost-crew", "mcp"] } } }
